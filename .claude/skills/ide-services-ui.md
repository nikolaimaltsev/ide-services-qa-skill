# IDE Services interaction
- use browser-use.mcp to interact with IDE Services UI
- AI Enterprise and IDE Provisioner have both General Settings and Profile level toggles, License Vault has only General settings toggle
- Make sure to save your changes with Save button
- Check official documentation when in doubt

# IDE Provisioner
- To apply new settings to IDE instantly, you need to "Check for updates" in Toolbox (otherwise they only come with scheduled update), and sometimes "Refresh Managed Settings" in the IDE"
